# 도움말에서 일부 설명 아이콘이 표시되지 않음

**Symptom**: 메모장 저장·목록·다운로드와 목록 검색·닫기 설명 앞의 아이콘이 도움말에서 빠진다. 코드 대조로 확인했으며 브라우저 실행으로는 재현하지 않았다.

**Observed evidence**: `docs/manual.md`는 `<!-- 아이콘: 디스크 저장 -->`, `목록`, `다운로드`, `돋보기`, `닫기`를 사용하지만 `app/help/page.tsx`의 `ICONS`에는 이 이름들이 없다. 주석은 이미지로 치환된 뒤 `img` 렌더러에서 해당 이름을 찾지 못하면 `null`이 된다.

**Suspected cause**: 매뉴얼에 주석을 추가할 때 도움말 아이콘 이름 대응표가 함께 갱신되지 않은 것으로 보인다.

**What was tried**: 문서 정리 중 주석 이름과 대응표를 대조했다. 앱 코드는 바꾸지 않았다.

**Proposed next step**: `/help`에서 해당 설명을 열어 누락을 확인한 뒤 실제 조작과 같은 아이콘을 이름별로 연결한다.
