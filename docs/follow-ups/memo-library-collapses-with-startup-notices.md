# 작은 화면에서 첫 안내가 메모 목록의 공간을 가리는 경우

**Symptom**: 320×568 화면의 아주 큰 글자 설정에서 저장 위치·설치 안내를 닫지 않으면 저장한 메모 목록 항목을 누르기 어렵다.

**Observed evidence**: 2026-11-02 Chromium, /memo, data-text-size=xlarge. 메모 저장 뒤 목록에서 항목 불러오기를 누르는 Playwright 검증에서 memo-status 또는 ‘메모 복사와 파일’ 도구 모음이 클릭을 가로챘다. 안내를 확인하고 설치 안내를 닫은 뒤 같은 조작과 확인 창 검증은 통과했다.

**Suspected cause**: 첫 안내·상단 헤더·도구 모음이 높이를 차지한 상태에서 메모 목록의 flex 영역이 지나치게 줄어드는 것으로 추정한다. 대화상자 자체의 스크롤 문제와는 별개다.

**What was tried**: 확인 창 점검에서는 먼저 첫 안내를 닫아 메모 불러오기·삭제 창을 검사했다. 창 높이·스크롤·포커스는 고쳤지만 목록의 최소 높이와 첫 안내 배치는 바꾸지 않았다.

**Proposed next step**: 같은 화면 크기와 글자 크기에서 첫 안내를 유지한 채 저장 목록의 높이를 측정하고, 도구 모음·목록·상태 표시가 겹치지 않도록 메모 화면의 최소 높이 또는 스크롤 영역을 조정한다.
