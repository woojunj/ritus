# 타이머 세션

## Decisions

- 큰 다이얼의 총 시간은 1～60분, 기본값은 25분이다. 반복 횟수는 따로 입력하지 않고 총 시간으로 정한다.
- 번갈아 반복은 기본으로 꺼져 있다. 두 구간은 각각 1초～1시간이고 기본값은 20초와 10초다. 구간에 이름은 붙이지 않는다.
- 작은 다이얼 한 바퀴는 60초이며, 그보다 긴 구간은 숫자로 입력하고 원은 다 채운 채로 둔다. 첫 구간 변경은 두 번째에도 따르지만, 두 번째를 직접 조정한 뒤에는 별개로 다룬다.
- 총 시간에 닿는 사이클은 두 구간을 모두 채우고 끝낸다. 구간이 총 시간보다 길어도 두 구간을 한 번씩은 돈다. 설정 화면은 실제 반복 횟수와 총 길이를 미리 보여 준다.
- 일시정지는 현재 구간과 전체 시간을 함께 멈춘다. 멈춘 횟수는 세지 않는다. 중도 종료는 메시지나 기록 없이 설정 화면으로 돌아간다.
- 완료하면 소리, 깜빡임과 무작위의 짧은 한국어 존댓말 격려를 보인다. 화면을 누르면 깜빡임을 멈추고, 같은 설정의 재시작과 설정 화면으로 돌아가기를 제공한다.
- 탭 제목은 세션 전체 남은 시간과 제목을 표시한다. 남은 시간은 틱 누적이 아니라 목표 시각과의 차이로 계산하고, 화면으로 돌아오면 다시 맞춘다.
- 효과음은 음원 파일 없이 앱이 직접 낸다. 두 구간의 전환음은 높이가 다르며 짧은 구간에서도 겹치지 않게 짧게 낸다.
- 지원하는 브라우저에서는 세션 진행 중 화면 꺼짐을 막고, 일시정지나 종료 때 놓는다. 앱을 다시 띄우면 잠금을 다시 요청한다.

## Why

- 총 시간과 반복 횟수를 함께 정하게 하면 시작 전에 할 일이 늘어난다. 두 번째 구간까지 채우는 것은 운동이나 휴식 한 짝이 중간에 사라지는 것을 막는다.
- 작은 다이얼과 큰 다이얼은 같은 60눈금 원리를 쓰되, 짧은 호흡 구간을 초 단위로 잡을 수 있게 한다.
- 중도 종료를 사건으로 취급하거나 일시정지 횟수를 보이면 사용자를 판정하게 된다. 탭 제목은 다른 탭으로 샜다가 돌아올 통로다.
- 브라우저가 백그라운드 실행을 늦춰도 세션 길이가 늘어나면 안 된다. 화면 꺼짐 방지는 소리와 타이머가 멈추는 상황을 줄인다.

## Boundaries

- 새로고침이나 탭을 닫은 뒤 세션을 복구하지 않는다. 세션 기록, 구간 프리셋과 세 구간 이상은 다루지 않는다.
- 1초마다 울리는 호흡 박자와 화면이 꺼진 동안의 소리 유지는 제품의 요구로 남아 있다. 현재 구현 완료로 취급하지 않는다.

## Evidence worth preserving

- 아이패드에서 다른 앱이나 홈 화면으로 가면 소리가 멈춘다. 돌아온 뒤 화면을 한 번 눌러야 소리가 다시 나며 늦을 수도 있다. 현재 한계와 재검토 방법은 [남은 일](../remaining-work.md)에 둔다.
