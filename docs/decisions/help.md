# 도움말

## Decisions

- `/help`는 `docs/manual.md`를 빌드 때 읽어 그대로 보여 준다. 별도 사용법 원본을 만들지 않는다. 문서 내 제목 링크가 동작하도록 제목에 id를 붙인다.
- 도움말은 모든 화면에서 헤더로 연다. 세션 중에도 열 수 있고 한 줄 바를 유지한다. 마크다운 렌더러는 메모장 프리뷰와 함께 쓴다.
- 도움말 안의 아이콘과 도우미 복사 버튼 자리는 매뉴얼의 HTML 주석으로 표시하고 `app/help/page.tsx`가 해당 부품을 끼운다.
- 복사할 빈 양식의 원본은 매뉴얼에 복제하지 않는다. `helperRequest`가 `noteToText`로 빈 양식을 만들고 쓴 글은 담지 않는다. 양식만 정리하는 부탁과 신호 판단까지 요청하는 부탁을 따로 고를 수 있다.

## Why

- 사용법을 문서와 화면 두 곳에 쓰면 서로 어긋난다. 원본 하나와 부품 자리 표시를 쓰면 저장소에서도 읽히고 앱에서는 실제 조작을 제공한다.
- 한 장 화면에 조작을 더 늘리지 않고 도움말에서 빈 양식을 전달한다. 양식 원본을 코드 한 곳에 두어 복사와 붙여넣기 형식이 어긋나는 일을 줄인다.

## Boundaries

- 별도 도움말 검색, 화면별 도움말 분리와 영상은 다루지 않는다.
