# 메모장

## Decisions

- 편집하는 문서는 앱 전체에 하나이며 할 일이나 세션에 묶이지 않는다. 세션 중에도 글을 쓸 수 있다. 일반 텍스트와 마크다운을 다루고 고른 형식도 기억한다.
- 편집 문서는 자동 저장한다. 디스크 저장은 그 글의 복사본을 목록에 한 장 더 남기며 쓰던 글을 비우지 않는다. 파일 내려받기는 별도 화살표 조작으로 둔다.
- 저장 목록은 메모장 안에서 편집 자리와 전환한다. 장 수 제한 없이 저장 날짜·시각과 첫 줄을 카드로 보이고, 삭제는 확인을 거친다. 제목을 따로 붙이거나 정렬을 바꾸지 않는다.
- 목록의 메모를 불러올 때 현재 글이 있으면 확인을 받고 한 칸짜리 임시 보관에 넣는다. 이전 임시 보관을 덮어쓸 때는 알린다. 임시 보관본은 맨 위에서 되돌릴 수 있고, 이를 불러올 때는 현재 글과 바꿔 담는다.
- txt/md 파일 불러오기는 글과 형식을 통째로 바꾼다. 현재 글이 있으면 확인하며 뒤에 이어 붙이지 않는다.
- 마크다운은 넓은 화면에서 편집 옆에, 좁은 화면에서는 편집과 전환해 미리 본다. HTML이나 스크립트를 실행하지 않는다.
- 상태 표시줄은 `Ln`, `Col`, `Pos`와 한국어 줄·글자 수를 쓴다. 위치는 1부터 세며 개행도 포함한다. 전체 글자 수와 공백·개행을 제외한 수를 함께 보인다. 화면에 보이는 한글 한 글자와 이모지 하나는 각각 1자다.

## Why

- 문서 하나를 계속 쓰는 자동 저장과, 특정 시점의 글을 모아 두는 목록 저장은 목적이 다르다. 글을 불러올 때 한 칸 임시 보관을 두어 쓰던 글을 되돌릴 길을 남긴다.
- 여러 문서를 동시에 편집하거나 할 일별 메모를 두지 않아 글쓰기의 진입을 단순하게 유지한다.
- 위치 약어는 편집기에서 익숙한 표기를 쓰고, 줄 수와 글자 수는 한국어로 읽히게 한다.

## Boundaries

- 고급 찾기·바꾸기나 별도의 되돌리기 기록 관리, 서식 버튼은 두지 않는다. 저장 목록 검색 규칙은 [목록 검색과 단축키](search-and-keyboard.md)가 맡는다.
- 저장 목록과 임시 보관은 [전체 백업](storage-and-backup.md)에 포함한다.
