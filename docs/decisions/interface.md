# 아이콘과 반응형 배치

## Decisions

- 반복 조작은 통용 아이콘을 우선하고 접근성 이름과 상태를 유지한다. 그만두기는 정지, 다시 시작은 되돌리기 아이콘을 쓴다. 구간은 숫자와 색으로 구분한다.
- 제목, 시간과 단위, 격려, 확인 문구, 양심노트의 덕목·안내 질문·신호처럼 뜻을 아이콘만으로 전하기 어려운 글은 남긴다.
- 화면 이동은 같은 순서의 상단 아이콘으로 두고 현재 화면을 강조한다. 좁은 화면에서는 앱 이름을 감추고, 공간이 부족하면 헤더의 조작 묶음을 다음 줄로 넘긴다.
- 넓은 설정 화면에서는 중앙의 제목·총 시간·시작 흐름을 유지하면서 반복 설정만 오른쪽에 둔다. 좁으면 아래에 펼친다. 전환은 화면 폭으로 정하고 토글을 껐다 켜도 설정값은 보존한다.
- 마우스를 올렸을 때 아이콘 이름을 보여 준다. 밝은 테마와 어두운 테마에서 모두 읽혀야 하며 크게 보기에서도 조작이 화면 밖으로 밀리지 않아야 한다.

## Why

- 닫기나 재생을 그만두기·다시 시작에 재사용하면 뜻이 겹친다. 접근성 이름은 화면 글자를 줄이더라도 조작 의미를 유지한다.
- 넓은 화면의 반복 설정 때문에 세로 스크롤이 생기던 불편은 오른쪽 여백으로 해결한다. 전체를 두 칸으로 재구성하면 반복을 켤 때 화면 구조가 크게 변한다.
- 스크롤 발생 감지나 종횡비 분기보다 기존의 폭 기준 반응형 배치가 단순하다. 정확한 임계값·색·간격은 코드에서 관리한다.

## Reconsider when

- 다른 사람에게 앱을 열 때 아이콘만으로 뜻을 이해하는지 다시 확인한다. 다국어 번역의 경계는 `PRODUCT.md`에서 다룬다.
