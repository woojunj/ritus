# 저장과 백업

## Decisions

- 메모, 저장 목록·임시 보관, 할 일과 양심노트는 브라우저에 로컬 저장한다. 계정·서버 동기화의 경계는 `PRODUCT.md`를 따른다. 자동 저장과 사용자가 만드는 백업 파일은 별개다.
- 전체 백업은 `ritus-backup-YYYYMMDD.json` 한 파일로 데이터를 그대로 담는다. 저장한 메모와 임시 보관도 포함하며, 해당 필드가 없는 예전 파일은 빈 목록으로 읽는다. 소리와 테마 설정은 담지 않는다.
- 헤더의 백업 버튼 하나에서 전체 저장과 불러오기를 고른다. 불러오기는 현재 내용과 파일 내용을 요약하고 확인받은 뒤 전체를 교체한다. 취소하면 바꾸지 않는다. 합치기·화면별 선택 복원·복원 되돌리기는 제공하지 않는다.
- 일부 데이터의 모양이 맞지 않으면 교체 전에 알리고, 읽을 수 없는 항목은 건너뛰거나 칸을 비운다. ritus 백업 자체가 아니면 교체하지 않는다.
- 기존 내용에 더하는 것은 화면별 불러오기가 맡는다. 양심노트는 같은 내용의 장, 할 일은 같은 제목을 건너뛴다. 메모장의 단일 파일 불러오기는 현재 문서를 교체한다.
- 사람이 읽는 글 파일은 UTF-8 BOM을 붙인다. 할 일 CSV에서 `=`, `+`, `-`, `@`로 시작하는 제목은 내려받을 때 앞에 `'`를 붙이고 다시 불러올 때 뗀다.

## Why

- 전체 백업 복원은 파일 시점으로 되돌린다는 뜻이다. 합치면 편집 문서와 완주 횟수 등 화면마다 충돌 규칙이 달라져 결과를 예측하기 어렵다.
- 테마와 음소거는 기기별 선호다. 전체 파일은 데이터 보관, 화면별 텍스트 파일은 사람이 읽고 더하는 용도로 나눈다.
- 헤더에는 아이콘을 둘 더 놓을 공간이 없어 백업 진입을 하나로 묶는다. BOM은 기본 메모 앱에서 한글이 깨져 보이는 일을 줄이고, CSV 접두사는 제목이 수식으로 실행되는 일을 막는다.

## Boundaries

- 백업 파일과 로컬 저장은 암호화된 보관소가 아니다. 현재 사용자 안내는 [매뉴얼](../manual.md)의 개인정보 절에서 관리한다.
