# 할 일 목록

## Decisions

- 완료 체크는 사용자가 직접 켜고 끄는 상태이며 삭제와 별개다. 체크하면 원래 자리에 비활성 상태로 남고, 해제하면 다시 활성화된다. 비활성 카드는 타이머 진입과 방향키·Space 선택에서 제외하지만 삭제 편집과 검색에는 남는다.
- 타이머 완주 횟수와 완료 체크는 서로 바꾸지 않는다. 체크는 진행 중인 세션도 멈추지 않는다.
- 체크 상태는 브라우저 저장, 전체 백업과 할 일 CSV에 포함한다. 이전 자료에 체크 정보가 없으면 미체크로 읽는다. CSV의 같은 제목 건너뛰기 규칙은 유지한다.

## Why

- 끝낸 항목을 삭제하지 않고 잠시 비활성화했다가 다시 쓸 수 있어야 한다. 자동으로 완료를 판정하지 않고 사용자가 체크한다.
- 타이머를 한 번 완주한 것과 할 일을 끝냈다는 판단은 다르다. 백업이나 파일 이동 뒤에도 그 구분을 보존한다.
