# 양심노트

## Decisions

- 양심노트는 사안마다 한 장을 쌓는 독립 기록이다. 세션, 할 일, 메모와 연결하지 않는다.
- 홍익학당 양심노트 양식(A4, 20191010)의 날짜, 사안, 몰입·사랑·정의·예절·성실·지혜, 최종 결론 순서를 따른다. 안내 질문은 원문 그대로 쓰고 입력 중에도 보이게 둔다. 원문과 축 배치의 코드 원본은 `features/conscience-note/lib/form.ts`다.
- 신호는 찜찜·찜자·자찜·자명이며 선택을 해제할 수 있다. 중심부터 바깥 순서로 도표에 반영하고 선택하지 않은 덕목은 도형에서 뺀다. 도표는 보기만 하며 신호를 고르는 입력 수단으로 쓰지 않는다.
- 평가는 쓰는 사람이 한다. 앱은 신호를 합산·평균내거나 좋고 나쁨을 매기지 않는다. 도우미의 신호 판단을 요청하는 복사는 선택 사항이며 결과는 사람이 확인한다.
- 사용법은 실제 양심노트 화면에서 도움말을 눌러 여는 반투명 레이어와 화살표로 안내한다. 첫 방문에 강제로 시작하지 않으며 안내 자체는 노트나 신호를 바꾸지 않는다. 게임화보다 실제 작성 화면의 사용법을 익히는 것을 우선한다.
- 자동 저장하고 그 상태를 보인다. 완료는 목록으로 돌아가는 동작이며 별도 저장이 아니다. 새로 만든 빈 장도 남기고 삭제는 확인을 받는다.
- 목록 붙여넣기는 새 장을 만들고 여러 장도 받는다. 한 장 화면에서는 빈 칸을 채우고 기존 글에는 한 줄 띄워 이어 붙이며 기존 날짜와 선택한 신호를 유지한다. 여러 장은 한 장 화면에 섞지 않고 목록에서 받는다.
- 붙여넣기는 덕목 이름이 있는 줄을 구획으로 읽고, 구획 전의 글이나 구획 없는 글은 사안으로 넣는다. 클립보드 권한이 없으면 직접 붙여넣는 창을 제공한다.
- 도우미는 외부 ChatGPT를 새 탭으로 열 뿐 쓴 글을 보내지 않는다. 사용자가 직접 복사·붙여넣기한다. 양식 복사에는 부탁하는 말과 빈 양식만 넣고, 답변 앞에 해당 질문을 짧게 적어 달라고 요청한다.
- 출처와 허가 없는 상업적 활용을 금하는 원문의 저작권 문구를 표시한다. 한국어 양식만 다룬다.

## Why

- 안내 질문을 풀어 쓰거나 덕목 이름만 남기는 대신 원문을 유지하기로 했다. placeholder는 쓰기 시작하면 사라지므로 질문을 별도 글자로 둔다.
- 방사형 도표는 여섯 덕목을 한눈에 보게 해 주지만 점수나 순위를 만드는 수단은 아니다.
- 저장 버튼을 요구하면 누르지 않고 이동할 때 글을 잃는다. 자동 저장 표시와 완료 동작으로 저장 여부의 불안을 줄인다.
- 개인적인 성찰 글은 외부 서비스로 자동 전송하지 않는다. 양식에 질문도 남기면 나중에 어떤 질문의 답인지 알 수 있다.

## Boundaries

- A4 인쇄, 외국어·어린이용 양식, 통계·추이·덕목별 평균은 범위 밖이다.

## Reconsider when

- 강의 자료로 배포하거나 다른 사람에게 앱을 열 때 양식 원문의 이용 허가를 확인한다.
- 본문에 `[사안]`이나 `[몰입]` 같은 구획 줄을 그대로 적으면 텍스트 불러오기 결과가 달라질 수 있다. 무손실 보관은 전체 JSON 백업을 쓴다.
