# 목록 검색과 단축키

## Decisions

- 검색은 돋보기로 목록 위 한 줄을 열고 닫기와 함께 지운다. 띄어쓰기로 나눈 낱말이 모두 들어 있어야 일치하고, 영문 대소문자는 가리지 않는다. 검색어와 글은 기기 밖으로 보내지 않는다.
- 양심노트는 사안·덕목 답·최종 결론을 검색하고 일치한 칸 이름을 보인다. 날짜와 신호는 글 검색에 넣지 않는다. 신호 칩은 신호 이름으로 표시하며 여러 개를 켜면 어느 덕목에서든 그중 하나를 고른 장을 남긴다. 글 검색과 칩은 두 조건을 모두 만족해야 한다.
- 할 일은 제목만 검색한다. 메모장은 저장 목록 본문과 임시 보관본을 검색하며 편집 중인 문서 안에서 찾기는 하지 않는다.
- 검색 중에도 목록의 기존 조작을 유지한다. 목록을 떠나면 검색 상태를 지운다. 할 일의 세션 교체 확인을 취소하면 검색을 유지하고, 확인하면 지운다. 양심노트 칩도 검색과 함께 지운다.
- `/`는 입력 칸 밖에서 해당 목록의 검색을 열고 커서를 옮긴다. 이미 열려 있으면 커서만 옮긴다. 조합 중이거나 Ctrl·Cmd·Alt 조합이면 가로채지 않는다. 파이어폭스의 `/` 빠른 찾기 대신 앱 검색을 열며, 페이지 검색은 Ctrl+F를 쓴다.
- Ctrl+S/Cmd+S는 메모장 입력 중에도 목록 저장을 한다. 이 경우 브라우저 페이지 저장을 막되 Shift·Alt 조합은 쓰지 않는다.
- Space는 아무 곳에도 포커스가 없을 때 설정에서 시작, 진행 중 일시정지·재개, 완료에서 재시작을 한다. 입력 칸이나 버튼에 포커스가 있으면 원래 동작을 따른다. 빈 곳을 누르면 포커스를 푼다.
- 할 일 목록은 편집 모드가 아니고 포커스가 없을 때 위아래 키로 카드를 고르고 Space로 누른다. 끝에서는 멈추며 고른 카드를 화면 안에 보이게 한다. 검색어를 바꾸면 선택을 초기화한다.
- Enter에 별도 앱 동작을 붙이지 않는다. Tab과 Shift+Tab으로 칸·버튼 사이를 옮기는 브라우저 동작을 유지하며 포커스를 표시한다. 타이머 설정에는 방향키 전역 동작을 두지 않는다.

## Why

- 같은 방식의 검색을 세 목록에 적용해 화면마다 새로 배울 일을 줄인다. 검색은 임시로 좁혀 보는 상태이므로 저장하지 않는다.
- 신호 이름은 점 개수보다 의미를 바로 읽을 수 있다. 평가하는 표현은 붙이지 않는다.
- 입력·버튼의 기본 키 의미와 앱 단축키를 겹치게 하면 입력 중 세션이 바뀔 수 있다. Enter는 누르기와 줄바꿈에 이미 쓰이므로 추가 의미를 주지 않는다.

## Boundaries

- 날짜 범위, 오타 허용, 형태 변화 인식, 정규식, 화면 통합 검색과 키 재설정은 다루지 않는다.
