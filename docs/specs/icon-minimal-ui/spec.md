# 아이콘 기반 UI 최소화

## 사용자에게 보이는 결과

세션 조작에 쓰이는 반복 동작 버튼(시작, 일시정지/이어서, 그만두기, 다시 시작, 번갈아 반복 켜기)이 통용 아이콘으로 바뀌어 텍스트 없이도 뜻이 통한다. 두 구간을 구분하는 라벨(구간 1/2, 첫 구간/두 번째 구간)은 숫자와 색으로 압축된다. 구간 다이얼에는 분 다이얼처럼 값과 "초" 단위가 함께 보인다.

## 승인된 범위

- 시작 버튼 → 재생 아이콘
- 일시정지/이어서 버튼 → 일시정지/재생 토글 아이콘
- 그만두기 버튼 → 정지(■) 아이콘
- 다시 시작 버튼 → 되돌리기(↺) 아이콘
- 번갈아 반복 켜기/끄기 토글 → 반복 아이콘 (버튼 문구는 "구간 반복"에서 "번갈아 반복"으로 바꾼다, `GLOSSARY.md` 참고)
- 실행 화면의 "구간 1"/"구간 2" 라벨 → 숫자·색 표시로 대체
- 설정 화면의 "첫 구간"/"두 번째 구간" 라벨 → 숫자·색 표시로 대체
- 구간 다이얼(초)에 분 다이얼과 같은 방식으로 값+"초" 오버레이 추가

## 수용 기준

- [x] 세션을 시작하는 버튼에 "시작"이라는 글자 없이 재생 아이콘만 보인다. 스크린리더는 여전히 "시작"을 읽는다.
- [x] 실행 중 버튼을 누르면 일시정지 아이콘으로, 다시 누르면 재생 아이콘으로 바뀐다. 텍스트는 화면에 보이지 않지만 스크린리더는 "일시정지"/"이어서"를 읽는다.
- [x] "그만두기" 버튼은 정지 아이콘만 보이고 스크린리더는 "그만두기"를 읽는다.
- [x] 종료 화면의 "다시 시작" 버튼은 되돌리기 아이콘만 보이고 스크린리더는 "다시 시작"을 읽는다.
- [x] 설정 화면의 "번갈아 반복" 토글은 반복 아이콘만 보이고, 켜짐/꺼짐 상태가 시각적으로 구분되며 스크린리더는 "번갈아 반복"과 켜짐/꺼짐 상태를 읽는다.
- [x] 실행 화면에서 번갈아 반복이 켜져 있으면, 지금 구간이 1번째인지 2번째인지 숫자나 색으로 구분되어 보인다. 지금처럼 남은 시간도 함께 보인다.
- [x] 설정 화면에서 번갈아 반복을 켜면, 두 다이얼이 각각 몇 번째 구간인지 숫자나 색으로 구분되어 보인다.
- [x] 설정 화면에서 번갈아 반복을 켜면, 각 다이얼 위에 지금 값과 "초"가 분 다이얼과 같은 자리(다이얼 중심)에 함께 보인다.
- [x] "직접 입력" 라벨, 분 다이얼의 "분" 표시, 세션 제목 입력창의 placeholder, 세션 종료 시 격려 문구는 지금처럼 텍스트로 남는다.

## 확정된 제약과 근거

- 다국어 번역은 다루지 않는다. `PRODUCT.md`의 결정("화면의 기능 표시는 아이콘을 우선하고, 고정 텍스트는 최소로 둔다. 다국어 번역은 지금 범위 밖이다")을 따른다.
- 아이콘으로 바뀌는 요소는 화면에서 텍스트를 감추되, 접근성 텍스트(스크린리더용)는 유지한다. 기존 음소거·테마 선택 버튼이 이미 이 방식을 쓰고 있어 새 패턴이 아니다.
- "그만두기"는 정지(■), "다시 시작"은 되돌리기(↺) 아이콘을 쓴다. 둘 다 닫기(X)나 재생(▶) 같은 다른 뜻으로 흔히 읽히는 아이콘과 헷갈리지 않도록 고른 것이다.

## 가정

- 구간 라벨과 초 단위 표시의 정확한 배색·배치는 구현 시점에 정한다. 접근 가능한 색 대비와 다이얼 크기 안에서 겹치지 않는 것만 이번 기준으로 두고, 구체적 색상 값은 스펙에 못박지 않는다.

## 범위 밖

- 세션 제목, 종료 시 격려 문구: 사용자가 직접 입력하거나 앱이 감성적으로 전하는 문구라 아이콘으로 대체할 대상이 아니다.
- "직접 입력" 라벨, 분 단위 표시: 뜻이 이미 짧고 아이콘으로 바꾸면 오히려 불분명해진다고 판단해 텍스트로 남긴다.
- 다국어 번역: `PRODUCT.md`에서 이미 범위 밖으로 정했다.
