# 전체 백업

## 사용자에게 보이는 결과

헤더의 테마 버튼 왼쪽에 백업 아이콘이 생긴다. 누르면 작은 창이 뜨고, "전체 저장"을 누르면 양심노트, 메모, 할 일이 파일 하나로 내려받아진다. 그 파일을 iCloud Drive나 구글 드라이브에 직접 두면 클라우드 백업이 된다.

같은 창의 "불러오기"로 저장해 둔 파일을 고르면, 지금 내용과 백업 파일의 내용이 각각 무엇인지 보여 주고 확인을 받은 뒤 전체를 백업 파일의 내용으로 바꾼다.

## 정한 것

- **불러오면 합치지 않고 전체를 바꾼다.** 백업을 되살린다는 뜻에 가장 가깝고 결과를 예측하기 쉽다. 메모는 한 편뿐이라 합칠 방법이 애매하고, 할 일은 완주 횟수가 다른 같은 항목을 어떻게 볼지 정해야 해서 합치면 규칙이 화면마다 달라진다. 기존 내용에 더하고 싶을 때는 각 화면의 불러오기를 쓴다.
- **버튼은 헤더에 하나만 둔다.** 특정 화면에 속하지 않는 기능이고, 헤더에 아이콘을 둘 더 놓을 자리가 없다. 저장과 불러오기는 창 안에서 고른다.
- **파일은 `ritus-backup-YYYYMMDD.json` 하나다.** 저장된 그대로 담는다. 사람이 읽을 용도로는 각 화면의 txt 저장이 이미 있다.
- **소리 끔 설정과 테마는 담지 않는다.** 기기마다 다를 수 있다.

## 범위 밖

- 계정, 자동 동기화, 클라우드 서비스에 직접 저장하기. `PRODUCT.md`의 경계 그대로다.
- 불러올 때 합치기, 화면별로 골라 되살리기.
- 불러오기 되돌리기.

## 수용 기준

- [x] 네 화면 모두 헤더의 테마 버튼 왼쪽에 백업 아이콘이 보인다. 스크린리더는 "전체 백업"을 읽는다. 폰 너비에서도 헤더가 가로 스크롤 없이 한 줄에 들어온다.
- [x] 백업 아이콘을 누르면 "전체 저장", "불러오기", "닫기"가 든 창이 뜬다.
- [x] "전체 저장"을 누르면 양심노트, 메모(글과 형식), 할 일(완주 횟수 포함)이 `ritus-backup-YYYYMMDD.json` 한 파일로 내려받아지고 창이 닫힌다.
- [x] "불러오기"로 백업 파일을 고르면 지금 내용과 백업 파일의 내용이 "양심노트 3장, 할 일 5개, 메모 120자"처럼 한 줄씩 보이고, 지금 내용이 사라진다는 안내와 함께 확인을 받는다.
- [x] "바꾸기"를 누르면 양심노트, 메모, 할 일이 모두 백업 파일의 내용으로 바뀌고, 보고 있던 화면에 새로고침 없이 바로 나타난다. "취소"를 누르면 아무것도 바뀌지 않는다.
- [x] ritus 백업 파일이 아닌 파일을 고르면 아무것도 바꾸지 않고 "ritus 백업 파일이 아닙니다"라고 알린다.
