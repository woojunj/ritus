# 메모장

## 사용자에게 보이는 결과

타이머 화면 헤더의 할 일 목록 아이콘 옆에 메모장 아이콘이 생긴다. 누르면 화면이 메모장 중심으로 바뀐다. 타이머는 위쪽 한 줄 바로 줄어들어 작은 링, 남은 시간, 조작 아이콘만 남고, 그 아래 전체가 글 쓰는 영역이 된다. 세션이 도는 중이든 아니든 열 수 있고, 메모장을 열고 닫아도 세션은 끊기지 않는다.

쓴 글은 따로 저장하지 않아도 브라우저에 자동으로 남는다. 저장 버튼은 글을 파일로 내려받는다. 아래쪽 상태 표시줄에는 현재 커서 위치(Ln, Col, Pos), 전체 줄 수, 글자 수(전체, 그리고 공백·개행 제외)가 보인다. 형식을 txt와 md 중에서 고를 수 있고, md를 고르면 마크다운 프리뷰가 함께 보인다.

화면 배치는 다음과 같다.

```
┌──────────────────────────────────────┐
│ ◔ 12:34  ▶/❚❚ ■   ☰ ◐ 🔇   ✕        │  ← 작은 링 + 남은 시간 + 아이콘
├──────────────────────────────────────┤
│ [txt] [md]                    ⬇ 저장 │
├──────────────────────────────────────┤
│  메모 본문...                        │
├──────────────────────────────────────┤
│ Ln 3, Col 12, Pos 40 · 30줄 · 150자 … │
└──────────────────────────────────────┘
```

## 승인된 범위

### 묶음 1: 일반 텍스트 메모장

- 타이머 화면(`/`, `/timer`) 헤더에 메모장 열기 아이콘
- 메모장 화면: 상단 바(작은 링, 남은 시간, 세션 조작 아이콘, 기존 헤더 아이콘, 닫기), 본문 입력 영역, 상태 표시줄
- 앱 전체에 문서 하나. 입력하는 대로 브라우저에 자동 저장
- 저장 버튼: 현재 글을 파일로 내려받기
- 상태 표시줄: 현재 위치, 전체 줄 수, 글자 수(전체 / 공백·개행 제외)

### 묶음 2: txt/md 형식과 프리뷰

- txt/md 형식 선택 탭
- md를 고르면 마크다운 프리뷰 표시
- 내려받는 파일 확장자가 선택한 형식을 따름

묶음 1이 먼저 동작해야 하고, 묶음 2는 그 위에 올린다.

## 수용 기준

### 묶음 1

- [x] 타이머 화면 헤더에 메모장 아이콘이 할 일 목록 아이콘 옆에 보인다. 화면에는 글자 없이 아이콘만 보이고, 스크린리더는 "메모장"을 읽는다.
- [x] 메모장 아이콘을 누르면 상단 바와 본문 입력 영역, 상태 표시줄로 이루어진 메모장 화면이 열리고, 본문 입력 영역에 바로 입력할 수 있다.
- [x] 세션이 도는 중에 메모장을 열면 상단 바에 작은 링과 남은 시간이 계속 갱신되어 보인다. 구간 전환 소리, 박자 소리, 종료 소리도 메모장을 열기 전과 똑같이 울린다.
- [x] 메모장 상단 바에서 일시정지/이어서, 그만두기를 할 수 있다.
- [x] 세션이 돌지 않을 때 메모장을 열면 상단 바에 지금 설정된 시간과 시작 아이콘이 보이고, 시작하면 메모장을 연 채로 세션이 돈다.
- [x] 닫기 아이콘을 누르면 원래 타이머 화면으로 돌아온다. 세션이 돌고 있었다면 그대로 돌고 있다.
- [x] 글을 쓰고 저장 버튼을 누르지 않은 채 새로고침하거나 앱을 다시 열어도, 메모장을 열면 마지막으로 쓴 글이 그대로 있다.
- [x] 저장 버튼을 누르면 현재 글이 파일로 내려받아진다. 내려받은 파일을 열면 메모장의 글과 똑같다.
- [x] 상태 표시줄에 현재 커서 위치가 `Ln 10, Col 5, Pos 70` 형식으로 보이고, 커서를 옮기거나 입력하면 바로 바뀐다. 줄, 열, 위치는 모두 1부터 센다. Pos는 문서 처음부터 센 위치이며 개행도 한 글자로 친다. 예를 들어 "가나\n다"에서 "다" 앞의 커서는 `Ln 2, Col 1, Pos 4`다.
- [x] 상태 표시줄에 전체 줄 수가 보인다. 빈 문서는 1줄이다.
- [x] 상태 표시줄에 전체 글자 수와 공백·개행을 뺀 글자 수가 함께 보인다. 예를 들어 "가 나\n다"는 전체 5자, 공백·개행 제외 3자다.
- [x] 폰 너비에서도 상단 바, 본문, 상태 표시줄이 가로 스크롤 없이 한 화면에 들어온다.

### 묶음 2

- [x] 메모장에 txt/md 형식 탭이 있고, 기본값은 txt다.
- [x] md를 고르면 본문을 쓰는 동안 마크다운 프리뷰가 함께 보인다. 제목, 목록, 강조, 코드, 링크가 서식대로 그려진다.
- [x] txt를 고르면 프리뷰가 사라지고 일반 텍스트 메모장으로 돌아온다. 본문은 그대로다.
- [x] 고른 형식은 글과 함께 기억되어, 다시 열었을 때도 같은 형식으로 열린다.
- [x] 저장 버튼으로 내려받는 파일의 확장자가 txt일 때 `.txt`, md일 때 `.md`다.
- [x] 본문에 HTML이나 스크립트를 써도 프리뷰에서 실행되지 않는다.

## 확정된 제약과 근거

- **세션 중에도 쓸 수 있다.** 사용자가 정했다. 글쓰기 자체가 "지금 하기로 한 것"인 세션을 상정한다. 이 결정은 `PRODUCT.md`의 경험 원칙 "세션이 도는 동안 화면에는 지금 하기로 한 것과 남은 시간만 둔다"와 맞지 않는다. 이번 작업에서는 `PRODUCT.md`를 고치지 않고, 원칙 수정은 `define-product`로 따로 다룬다.
- **메모장을 열고 닫아도 세션이 끊기지 않는다.** 세션 중 사용이 핵심 용도이므로, 메모장은 세션을 끊는 페이지 이동이 아니라 같은 화면 안에서의 전환이어야 한다.
- **문서는 앱 전체에 하나다.** 사용자가 "앱의 메모장"으로 정했다. 할 일별 메모나 여러 문서는 다루지 않는다.
- **자동 저장은 브라우저에, 저장 버튼은 파일 내려받기다.** 브라우저에 자동으로 계속 저장하면 같은 곳에 저장하는 버튼은 할 일이 없다. 그래서 버튼은 파일 백업으로 쓰고, 임시본·저장본 두 개념을 두지 않는다. 저장 위치는 할 일 목록과 같은 기기 로컬 저장이며, `PRODUCT.md`의 "계정, 동기화, 여러 기기는 범위 밖"을 따른다.
- **배치는 상단 바 방식이다.** 사용자가 측면 패널, 떠 있는 미니 타이머와 비교해 골랐다. 폰과 PC에서 같은 구조를 써서 `PRODUCT.md`의 "큰 화면과 폰이 같은 하나의 화면을 쓴다"와도 맞는다.
- **아이콘을 우선한다.** 메모장 열기, 닫기, 저장 같은 조작은 아이콘으로 보이고 접근성 텍스트를 둔다(`docs/specs/icon-minimal-ui/` 방식).
- **위치 표기는 `Ln`, `Col`, `Pos`를 쓰고, 개수는 한국어로 쓴다.** 사용자가 처음 가정(`3:12`)보다 편집기에서 굳어진 표기를 택했다. 위치 약어는 VS Code, Notepad++ 등과 같아 바로 읽히고, "30줄", "150자" 같은 개수는 한국어가 자연스러워 섞어 쓴다. 전체 표기는 `Ln 10, Col 5, Pos 70 · 30줄 · 150자 (공백 제외 120)`이다.

## 가정

되돌리기 쉬워서 에이전트가 정한 기본값이다. 바꾸고 싶으면 언제든 바꾼다.

- 글자 수는 화면에 보이는 글자 단위로 센다. 완성된 한글 한 글자와 이모지 하나는 각각 1자다.
- 내려받는 파일 이름은 `ritus-memo-YYYYMMDD.txt`(또는 `.md`)로 한다.
- 넓은 화면에서 md 프리뷰는 본문 옆에, 좁은 화면에서는 편집과 프리뷰를 전환해서 본다.
- 세션 시간 조정(다이얼, 직접 입력)은 메모장 상단 바에 두지 않는다. 시간을 바꾸려면 메모장을 닫는다.
- 세션이 끝나면 메모장은 열린 채로 있고, 상단 바에 같은 설정으로 한 판 더 시작하는 아이콘이 보인다.

## 범위 밖

- 여러 문서, 할 일별 메모: 사용자가 문서 하나로 정했다.
- 파일 불러오기(업로드): 이번에는 내려받기만 다룬다.
- 기기 간 동기화, 서버 저장: `PRODUCT.md`에서 범위 밖이다.
- 마크다운 외 서식(굵게 버튼 같은 서식 도구 막대): 서식 없는 일반 텍스트에서 시작하기로 했다.
- 찾기/바꾸기, 되돌리기 기록 관리 같은 고급 편집 기능: 브라우저 기본 동작에 맡긴다.

## 보류

- `PRODUCT.md` 경험 원칙 수정: 세션 중 메모장 사용을 반영하도록 원칙 문구를 고치는 일은 `define-product`로 따로 한다.

## 남은 위험

- 자동 저장은 브라우저에만 남으므로 브라우저 데이터를 지우면 글이 사라진다. 홈 화면에 설치한 PWA는 iOS의 7일 삭제 정책을 피하지만, 사용자가 직접 지우는 경우는 막지 못한다. 저장 버튼으로 내려받는 것이 유일한 백업이다.
- 메모장 화면에서 세션 중 화면이 꺼지면 소리가 이어지는지는 기존 타이머와 같은 조건에 놓인다. 메모장 때문에 새로 생기는 위험은 아니지만 함께 확인해야 한다.
- 폰에서 가상 키보드가 올라오면 화면 높이가 줄어 상단 바나 상태 표시줄이 가려질 수 있다. 실기기에서 확인해야 한다.
