# Space로 타이머 시작

## 사용자에게 보이는 결과

타이머 설정 화면에서 아무 곳에도 포커스가 없을 때 Space를 누르면 "시작"과 같은 동작을 한다. 엔터는 쓰지 않는다.

## 정한 것

- **설정 화면에서만 동작한다.** 세션이 도는 중이나 종료 화면에서는 Space가 아무 일도 하지 않는다.
- **아무 것에도 포커스가 없을 때만 동작한다.** 버튼에 포커스가 있으면 Space는 그 버튼을 누르는 뜻이므로, 두 동작이 겹치지 않도록 버튼 포커스일 때는 무시한다. 입력 칸(제목, 시간, 구간 칸)에 커서가 있으면 글자로 쓰인다.
- **엔터는 쓰지 않는다.** 엔터는 버튼에서 누르기, 글 칸에서 줄바꿈처럼 이미 여러 뜻으로 쓰여서 헷갈린다.
- **빈 곳을 누르면 포커스가 풀린다.** 그래서 설정 화면에서 빈 곳을 한 번 누른 뒤 Space를 누르면 시작한다.

## 범위 밖

- 세션 중 Space로 일시정지하기.
- 엔터로 시작하기.

## 수용 기준

- [x] 설정 화면에서 포커스가 없을 때 Space를 누르면 세션이 시작한다.
- [x] 제목이나 시간 입력 칸에 커서가 있을 때 Space는 글자로 쓰이고 세션을 시작하지 않는다.
- [x] `docs/manual.md`의 단축키 절에 Space를 적는다.
