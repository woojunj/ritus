# 메모 저장 목록

## 사용자에게 보이는 결과

메모장 도구 줄에 디스크 모양의 **저장** 버튼이 생긴다. 누르면 지금 글이 저장된 메모 목록에 한 장으로 남는다. 목록은 양심노트 목록처럼 날짜와 첫 줄이 보이는 카드로 쌓인다. 카드를 누르면 그 메모를 불러온다. 쓰던 메모 한 편은 계속 남고, 저장은 그 글의 복사본을 따로 두는 것이다.

## 정한 것

- **저장 버튼은 복사하기와 파일로 저장 사이에 둔다.** 아이콘은 디스크 모양이다. 파일로 저장(화살표)과 파일 불러오기는 지금처럼 둔다.
- **저장한 메모는 장 수 제한 없이 쌓는다.** 양심노트와 같다.
- **목록은 메모장 화면 안에서 연다.** 도구 줄의 목록 아이콘을 누르면 편집 자리가 목록으로 바뀌고, 다시 누르면 편집으로 돌아온다.
- **카드에는 저장한 날짜와 시각, 첫 줄을 보인다.** 글이 비어 있으면 저장하지 않고 "저장할 글이 없습니다"를 잠깐 알린다.
- **카드에는 불러오기와 삭제를 둔다.** 삭제는 확인 창을 한 번 거친다.
- **불러올 때 지금 글이 있으면 경고한다.** 확인 창에서 "지금 글을 임시 보관하고 이 메모를 불러올까요?"라고 묻는다.
- **임시 보관은 한 칸이다.** 지금 글을 임시 보관 칸에 넣고, 이전 임시 보관본은 덮어쓴다. 덮어쓸 임시 보관본이 있으면 확인 창에서 그 사실을 알린다.
- **임시 보관본은 목록 맨 위에 "임시 보관" 표시와 함께 보인다.** 불러오기로 되돌릴 수 있다.
- **저장한 메모와 임시 보관본은 전체 저장 파일에 담는다.** 담지 않으면 백업에서 빠져 잃어버릴 수 있다. 예전 백업 파일에는 이 항목이 없으므로 그때는 빈 목록으로 읽는다.
- **모든 것은 이 기기 안에 저장하고, 어디로도 보내지 않는다.**

## 범위 밖

- 저장한 메모 검색, 이름 붙이기, 정렬 바꾸기.
- 저장한 메모를 개별 파일로 내려받기. 이미 있는 파일 저장 기능을 쓴다.
- 여러 기기 사이의 동기화.

## 용어집

- 메모장의 정의를 "앱 전체에 하나뿐인 일반 텍스트(또는 마크다운) 문서와, 그것을 쓰는 화면"에서 "쓰는 문서 한 편과, 저장해 둔 메모 목록을 함께 두는 화면"으로 고친다.

## 수용 기준

- [ ] 메모장 도구 줄에 디스크 아이콘의 저장 버튼이 복사하기와 파일로 저장 사이에 있다.
- [ ] 저장을 누르면 지금 글이 저장 목록에 날짜와 첫 줄과 함께 추가된다.
- [ ] 글이 비어 있으면 저장하지 않고 "저장할 글이 없습니다"를 잠깐 보인다.
- [ ] 목록 아이콘을 누르면 목록이 보이고, 다시 누르면 편집으로 돌아온다.
- [ ] 저장한 메모를 불러오면 지금 글이 임시 보관 칸에 들어가고, 불러온 메모가 편집 자리에 보인다.
- [ ] 지금 글이 있을 때 불러오기를 누르면 임시 보관을 알리는 확인 창이 먼저 뜬다.
- [ ] 임시 보관본은 목록 맨 위에 "임시 보관"으로 보이고, 불러오기로 되돌릴 수 있다.
- [ ] 임시 보관본이 이미 있으면 덮어쓴다는 사실을 확인 창에서 알린다.
- [ ] 삭제는 확인 창을 거친 뒤에만 지워진다.
- [ ] 전체 저장 파일에 저장한 메모와 임시 보관본이 담기고, 다시 불러와도 그대로 돌아온다.
- [ ] 예전 백업 파일을 불러와도 메모 목록은 빈 목록으로 읽히고 화면이 깨지지 않는다.

- [ ] `docs/manual.md`의 메모장 절에 저장과 목록 사용법을 적는다.
- [ ] `GLOSSARY.md`의 메모장 정의를 고친다.
