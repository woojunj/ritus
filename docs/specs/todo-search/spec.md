# 할 일 검색

## 사용자에게 보이는 결과

할 일 목록의 "할 일 N개" 오른쪽에 돋보기 아이콘이 생긴다. 누르면 목록 위에 검색 칸이 열리고, 글을 치면 그 글을 모두 포함한 할 일만 남는다. 닫기(×)를 누르면 전체 목록으로 돌아간다. 양심노트 검색과 같은 방식이다.

## 정한 것

- **검색 대상은 할 일 제목이다.** 완주 횟수는 검색하지 않는다.
- **일치 규칙은 양심노트 검색과 같다.** 띄어쓰기로 나눈 낱말을 모두 포함해야 하고, 영문은 대소문자를 구분하지 않는다. 한글은 조사가 붙어도 일치한다.
- **돋보기 위치.** 할 일 목록에는 페이지 제목이 없으므로, 제목 자리 역할을 하는 "할 일 N개" 바로 오른쪽에 둔다.
- **검색 칸과 닫기는 양심노트와 같다.** 검색 칸은 목록 위 한 줄로 열리고, 닫기(×)를 누르면 사라진다.
- **할 일 카드를 눌러 타이머를 시작하면 검색어를 지운다.** 세션을 그만두고 새로 시작하는 확인 창에서 "확인"을 눌러도 지운다. 취소하면 검색은 그대로 둔다.
- **편집 모드와 함께 쓸 수 있다.** 검색 중에도 편집, 복사, 저장, 불러오기는 지금처럼 동작한다.
- **일치하는 할 일이 없으면 "일치하는 할 일이 없습니다"를 보인다.**
- **검색은 이 기기 안에서만 한다.** 네트워크 요청을 하지 않는다.

## 범위 밖

- 완주 횟수로 거르기, 정렬 바꾸기.
- 여러 화면을 가로지르는 검색.

## 수용 기준

- [x] "할 일 N개" 오른쪽의 돋보기를 누르면 검색 칸이 목록 위에 열리고, 글을 치면 목록이 바로 줄어든다.
- [x] 띄어쓰기로 나눈 낱말을 모두 포함한 할 일만 남는다. 영문은 대소문자를 구분하지 않는다.
- [x] 일치하는 할 일이 없으면 "일치하는 할 일이 없습니다"가 보인다.
- [x] 닫기(×)를 누르면 검색 칸이 사라지고 전체 목록이 돌아온다.
- [x] 할 일 카드를 눌러 타이머를 시작하면 검색어가 지워진다.
- [x] 폰 너비(360px)에서 검색 칸이 열려도 가로 스크롤이 없다.
- [x] `docs/manual.md`의 할 일 목록 절에 검색 사용법을 함께 적는다.
