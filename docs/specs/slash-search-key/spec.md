# "/"로 검색 열기

## 사용자에게 보이는 결과

검색을 쓸 수 있는 목록 화면에서 키보드의 "/"를 누르면 검색 칸이 열리고 커서가 그 칸으로 간다. 이미 열려 있으면 커서만 칸으로 옮긴다. 돋보기를 누르는 것과 같은 결과이며, 돋보기는 그대로 둔다.

적용되는 곳은 셋이다.
- 양심노트 목록 (노트가 하나라도 있고, 한 장을 열지 않은 상태)
- 할 일 목록
- 메모장의 저장 목록 (저장한 메모나 임시 보관본이 있을 때)

## 정한 것

- **입력 칸 밖에서만 동작한다.** 글을 쓰는 칸(입력 칸, 글 칸, 선택 칸)에 커서가 있으면 "/"는 글자로 쓰인다.
- **Ctrl, Cmd, Alt 조합은 건드리지 않는다.** 브라우저 단축키와 겹치지 않게 하기 위해서다.
- **파이어폭스에서는 앱 검색이 이긴다.** 파이어폭스는 "/"로 빠른 찾기를 여는데, 앱이 이 키를 가로챈다. 페이지 안 글자를 찾으려면 Ctrl+F를 쓴다.
- **한글 입력 중에는 동작하지 않는다.** 조합 중인 키 입력은 무시한다.
- **검색어 규칙과 지우는 규칙은 돋보기와 같다.** 목록을 떠나면 검색어가 지워진다.
- **Ctrl+S(맥은 Cmd+S)는 메모장 저장에 쓴다.** 글 칸에 커서가 있어도 지금 글을 저장 목록에 저장하고, 브라우저의 페이지 저장은 막는다. Shift나 Alt를 함께 누른 조합은 쓰지 않는다.
- **다른 단축키는 이번 범위에 넣지 않는다.** 탭 전환 키는 따로 정한다.

## 범위 밖

- Ctrl+F 가로채기.
- 단축키 목록 화면이나 설정에서 키 바꾸기.
- 대화상자가 떠 있을 때 막기. 대화상자는 기존대로 포커스를 가둔다.

## 수용 기준

- [x] 양심노트 목록에서 입력 칸 밖에 커서가 있을 때 "/"를 누르면 검색 칸이 열리고 커서가 그 칸에 있다.
- [ ] 검색 칸이 이미 열려 있으면 "/"는 커서를 검색 칸으로 옮긴다.
- [x] 할 일 목록과 저장 목록에서도 같은 동작을 한다. 저장 목록은 목록을 보는 동안에만 동작한다.
- [x] 입력 칸에 커서가 있을 때 "/"는 글자로 쓰이고 검색 칸을 열지 않는다.
- [ ] Ctrl 또는 Cmd 또는 Alt를 함께 누르면 아무 일도 하지 않는다.
- [ ] 양심노트 한 장을 열고 있을 때는 "/"가 검색을 열지 않는다.
- [x] `docs/manual.md`의 단축키 절에 "/"와 파이어폭스 설명을 적는다.
