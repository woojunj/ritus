# 할 일 목록 키보드 선택

## 사용자에게 보이는 결과

할 일 목록에서 아무 곳에도 포커스가 없을 때 위아래 방향키로 카드를 고른다. 고른 카드에는 테두리가 생긴다. Space를 누르면 카드를 눌렀을 때처럼 그 할 일을 채운 설정 화면으로 간다. 거기서 Space를 누르면 시작한다.

## 정한 것

- **포커스가 없을 때만 동작한다.** 검색 칸이나 입력 칸에 커서가 있으면 방향키는 커서를 움직인다. 버튼에 포커스가 있을 때도 그 버튼의 동작을 따른다.
- **위아래 방향키로 고른다.** 맨 위에서 위로 누르면 첫 카드에 머문다. 맨 아래에서 아래로 누르면 마지막 카드에 머문다.
- **Space는 고른 카드를 누른 것과 같다.** 고른 카드가 없으면 Space는 아무 일도 하지 않는다. 세션이 도는 중에 다른 할 일을 고르면 카드를 누를 때처럼 확인을 받는다.
- **편집 중에는 쓰지 않는다.** 편집 모드에서는 방향키와 Space가 아무 일도 하지 않는다.
- **고른 카드는 화면 안에 보이도록 옮긴다.** 목록이 길어도 고른 카드가 가려지지 않는다.
- **엔터는 쓰지 않는다.** 엔터는 버튼과 글 칸에서 이미 다른 뜻으로 쓰이므로 헷갈린다.

## 범위 밖

- 고른 카드를 완주 처리하거나 편집하는 키보드 동작.
- 검색 결과 위에서의 키보드 선택은 검색 결과 목록을 그대로 따른다. 검색어를 바꾸면 고른 카드는 맨 위부터 다시 고른다.

## 수용 기준

- [ ] 포커스가 없을 때 아래 방향키를 누르면 첫 카드가 고르이고 테두리가 생긴다. 다시 누르면 다음 카드로 옮긴다.
- [ ] 고른 카드에서 Space를 누르면 그 할 일을 채운 설정 화면으로 간다. 설정 화면에서 Space를 누르면 시작한다.
- [ ] 편집 중이나 검색 칸에 커서가 있을 때는 방향키와 Space가 목록을 움직이지 않는다.
- [ ] `docs/manual.md`의 할 일 목록 절과 단축키 절에 적는다.
