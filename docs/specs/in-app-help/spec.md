# 앱 안의 도움말

## 사용자에게 보이는 결과

헤더 오른쪽 맨 앞에 도움말 아이콘이 생긴다. 누르면 `/help` 화면이 열리고, 저장소의 `docs/manual.md`가 서식대로 보인다. 사용법을 보려고 앱 밖으로 나갈 필요가 없다.

## 정한 것

- **문서는 하나다.** 도움말 화면은 `docs/manual.md`를 빌드할 때 읽어 그대로 그린다. 문서를 고치면 화면도 함께 바뀌므로 두 곳의 내용이 어긋나지 않는다.
- **아이콘은 헤더 오른쪽에 둔다.** 어느 화면에서든 한 번에 닿아야 한다. 자리를 내려고 폰 너비에서는 왼쪽의 "ritus" 이름을 감춘다.
- **마크다운을 그리는 부품은 메모장 프리뷰와 같이 쓴다.** `components/markdown.tsx`로 뽑았다.
- **문서 안의 `#전체-백업` 같은 링크가 닿도록** 제목에 GitHub와 같은 방식의 id를 붙인다.

## 범위 밖

- 도움말 안에서 검색하기, 목차 따로 두기.
- 화면마다 그 화면의 도움말만 보여 주기.
- 그림이나 영상.

## 수용 기준

- [x] 다섯 화면(타이머, 메모장, 할 일 목록, 양심노트, 도움말) 모두 헤더 오른쪽 맨 앞에 도움말 아이콘이 보인다. 스크린리더는 "도움말"을 읽는다.
- [x] 도움말 아이콘을 누르면 주소가 `/help`로 바뀌고 "ritus 사용법"으로 시작하는 문서가 제목, 목록, 굵은 글씨 서식대로 보인다. 도움말 화면에서는 이 아이콘이 현재 화면으로 강조된다.
- [x] 문서 안의 "전체 백업" 링크를 누르면 같은 화면의 전체 백업 절로 내려간다.
- [x] 세션이 도는 중에 도움말을 열어도 세션이 끊기지 않고, 헤더 아래 한 줄 바에 남은 시간이 보인다.
- [x] 폰 너비(360px)에서도 헤더가 가로 스크롤 없이 한 줄에 들어오고, 도움말 문서도 가로 스크롤 없이 세로로 이어진다.
