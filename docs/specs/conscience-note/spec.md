# 양심노트

## 사용자에게 보이는 결과

상단 헤더의 타이머, 메모장, 할 일 목록 아이콘 옆에 양심노트 아이콘이 생긴다. 누르면 양심노트 화면이 열리고, 지금까지 쓴 양심노트가 최근 날짜부터 목록으로 보인다.

새로 쓰기를 누르면 오늘 날짜가 채워진 빈 한 장이 열린다. 한 장은 홍익학당 양심노트 양식(A4, 20191010)을 따라 날짜, 사안, 여섯 덕목(몰입, 사랑, 정의, 예절, 성실, 지혜), 최종 결론으로 이루어진다. 덕목마다 양식의 안내 질문이 보이고, 그 아래에 글을 쓰며, 찜찜에서 자명까지 네 단계 중 하나를 고른다. 고른 단계는 최종 결론 옆의 육각형 방사형 도표에 바로 그려진다.

쓴 내용은 따로 저장하지 않아도 브라우저에 자동으로 남는다. 세션이 도는 중에도 열 수 있고, 양심노트를 오가도 세션은 끊기지 않는다.

한 장의 배치는 다음과 같다.

```
┌──────────────────────────────────────┐
│ ritus      ◷  ✎  ☰ [양심노트] │ ◐ ♪ │
├──────────────────────────────────────┤
│ 날짜  ✓ 자동 저장됨      삭제 [완료] │
│ 사안   ..........................    │
│ 몰입   (안내 질문)                   │
│        ..........................    │
│        ○찜찜 ○찜자 ○자찜 ○자명       │
│ 사랑 / 정의 / 예절 / 성실 / 지혜     │
│        (같은 구조)                   │
│ 최종 결론  ...............   ⬡ 도표  │
│ © 출처와 저작권 문구                 │
└──────────────────────────────────────┘
```

## 승인된 범위

- 네 화면 공통 헤더에 양심노트 아이콘 추가, 독립 화면으로 이동
- 양심노트 목록: 최근 날짜부터, 새로 쓰기, 열기
- 한 장 쓰기: 날짜, 사안, 여섯 덕목의 글과 단계, 최종 결론
- 덕목별 안내 질문을 양식 원문 그대로 표시
- 육각형 방사형 도표
- 브라우저 자동 저장, 한 장 삭제
- 출처와 저작권 문구 표시

## 양식의 문구

안내 질문은 양식 원문을 그대로 쓴다.

| 덕목 | 안내 질문 |
|---|---|
| 몰입 | 지금 이 순간 깨어있는가? / 당시에는 깨어있었는가? |
| 사랑 | 상대방의 입장을 내 입장처럼 진심으로 이해하고 배려했는가? |
| 정의 | 내가 당하기 싫은 일을 상대방에게 가하지는 않았는가? |
| 예절 | 처한 상황을 있는 그대로 진심으로 수용했는가? / 생각과 언행이 겸손하며 상황과 조화를 이루었는가? |
| 성실 | 양심의 인도를 따르는 데 최선의 노력을 기울였는가? |
| 지혜 | 나의 선택과 판단은 찜찜함 없이 자명한가? |

단계는 찜찜, 찜자, 자찜, 자명 넷이다. 도표에서는 찜찜이 중심이고 자명이 가장 바깥이다.

도표의 축은 위 왼쪽부터 시계 방향으로 예절, 성실, 정의, 지혜, 몰입, 사랑 순서다.

화면 아래에 다음 문구를 둔다: "© 이 양심노트의 내용과 형식은 저작권자(윤홍식) 또는 홍익학당의 허가 없이 상업적 용도로 활용하실 수 없습니다."

## 수용 기준

### 내비게이션

- [x] 타이머, 메모장, 할 일 목록, 양심노트 화면 모두 헤더의 같은 자리에 네 아이콘이 같은 순서로 보인다. 양심노트 아이콘은 할 일 목록 아이콘 다음이다.
- [x] 양심노트 아이콘은 글자 없이 아이콘만 보이고, 스크린리더는 "양심노트"를 읽는다. 양심노트 화면에서는 이 아이콘이 현재 화면으로 강조된다.
- [x] 양심노트 아이콘을 누르면 주소가 `/conscience`로 바뀌고 양심노트 화면이 열린다. 브라우저 뒤로가기를 누르면 이전 화면으로 돌아간다.
- [x] 폰 너비에서도 헤더가 가로 스크롤 없이 한 줄에 들어온다.

### 목록

- [x] 쓴 양심노트가 없으면 빈 목록과 새로 쓰기만 보인다.
- [x] 새로 쓰기를 누르면 오늘 날짜가 채워진 빈 한 장이 열리고, 사안 칸에 바로 입력할 수 있다.
- [x] 목록의 각 항목에 날짜와 사안의 첫 줄이 보인다. 사안이 비어 있으면 날짜만 보인다.
- [x] 목록은 날짜가 최근인 것부터 보인다.
- [x] 목록의 항목을 누르면 그 한 장이 쓴 내용 그대로 열린다.
- [x] 덕목의 단계를 하나라도 고른 한 장은 목록 항목 오른쪽에 그 모양을 그린 작은 도표(원 안의 도형)가 보인다. 단계를 고르지 않은 한 장에는 보이지 않는다.
- [x] 목록의 각 항목에 삭제 아이콘이 있고, 누르면 한 장 화면의 삭제와 같은 확인을 거쳐 그 한 장만 지운다.
- [x] 한 장의 완료 버튼을 누르면 목록으로 돌아간다. 뒤로 가는 화살표는 두지 않는다.
- [x] 목록의 저장 아이콘을 누르면 모든 한 장이 목록 순서대로 이어진 txt 파일(`ritus-conscience-all-YYYYMMDD.txt`)로 내려받아진다. 한 장도 없으면 이 아이콘은 보이지 않는다.
- [x] 목록의 불러오기 아이콘으로 내려받은 txt 파일(한 장짜리와 모두 받은 것 둘 다)을 고르면 그 한 장들이 날짜, 글, 고른 단계 그대로 목록에 더해진다. 이미 같은 내용의 한 장이 있으면 건너뛴다.

### 한 장 쓰기

- [x] 한 장에 날짜, 사안, 몰입, 사랑, 정의, 예절, 성실, 지혜, 최종 결론이 이 순서로 보인다.
- [x] 날짜를 다른 날로 바꿀 수 있다.
- [x] 날짜 옆에 "자동 저장됨" 표시가 보이고, 글을 쓰거나 단계를 고르면 잠깐 "저장 중…"으로 바뀌었다가 돌아온다.
- [x] 여섯 덕목마다 「양식의 문구」의 안내 질문이 원문 그대로 보이고, 그 아래에 여러 줄 글을 쓸 수 있다. 안내 질문은 고칠 수 없는 글자이며, 글을 쓰는 동안에도 계속 보인다.
- [x] 여섯 덕목마다 찜찜, 찜자, 자찜, 자명 중 하나를 고를 수 있다. 처음에는 아무것도 골라져 있지 않고, 고른 것을 다시 눌러 해제할 수 있다.
- [x] 삭제 아이콘 옆의 복사 아이콘을 누르면 그 한 장이 날짜, 사안, 여섯 덕목(고른 단계 포함), 최종 결론 순서의 일반 텍스트로 클립보드에 담긴다. 안내 질문은 담지 않는다.
- [x] 복사 아이콘 옆의 저장 아이콘을 누르면 그 한 장이 복사와 같은 내용의 txt 파일로 내려받아진다. 파일 이름은 `ritus-conscience-YYYYMMDD.txt`이고 날짜는 그 한 장의 날짜다.
- [x] 복사 아이콘 옆의 도우미 아이콘을 누르면 홍익학당 양심성찰 도우미(ChatGPT)가 새 탭으로 열린다. 쓰던 한 장은 그대로 남는다. 스크린리더는 "양심성찰 도우미 열기"를 읽는다.
- [x] 화면 아래에 출처와 저작권 문구가 보인다.
- [x] 폰 너비에서도 한 장 전체가 가로 스크롤 없이 세로로 이어진다.

### 방사형 도표

- [x] 최종 결론 옆에 여섯 축과 세 겹의 동심원으로 이루어진 도표가 보이고, 축 끝에 덕목 이름이 「양식의 문구」의 순서대로 적혀 있다.
- [x] 덕목의 단계를 고르면 그 축의 해당 위치에 점이 찍힌다. 찜찜은 중심, 자명은 가장 바깥 원이다.
- [x] 단계를 고른 덕목의 점들이 선으로 이어져 도형을 이룬다. 여섯 덕목을 모두 자명으로 고르면 가장 바깥 육각형과 겹친다.
- [x] 단계를 바꾸면 도표가 바로 바뀐다. 단계를 고르지 않은 덕목은 도형에 들어가지 않는다.

### 저장과 삭제

- [x] 글을 쓰거나 단계를 고른 뒤 새로고침하거나 앱을 다시 열어도, 목록에서 그 한 장을 열면 마지막 상태 그대로다.
- [x] 한 장을 삭제하면 지울지 먼저 묻고, 확인하면 목록에서 사라진다. 새로고침해도 돌아오지 않는다.
- [x] 다른 한 장들은 삭제에 영향을 받지 않는다.

### 세션

- [x] 세션이 도는 중에 양심노트로 이동해도 남은 시간이 끊기지 않고 줄어들며, 구간 전환 소리, 박자 소리, 종료 소리가 그대로 울린다.
- [x] 세션이 돌거나, 일시정지됐거나, 막 끝났을 때는 헤더 아래에 한 줄 바가 보이고, 할 일 목록에서와 똑같이 동작한다.

## 확정된 제약과 근거

- **사안마다 한 장씩 쌓인다.** 사용자가 정했다. 양식에 날짜와 사안 칸이 있어 일 하나에 한 장을 쓰는 것이 원래 쓰임이다. 문서가 하나뿐인 메모장과 다르다.
- **방사형 도표를 넣는다.** 사용자가 정했다. 여섯 덕목을 한눈에 보는 도표가 이 양식을 메모장과 구분한다.
- **안내 질문은 양식 원문 그대로 쓴다.** 사용자가 정했다. 풀어 쓴 문구, 덕목 이름만 두는 안과 비교해 골랐다.
- **평가는 쓰는 사람이 한다.** 앱은 단계를 점수로 바꾸거나, 합계나 평균을 내거나, 좋고 나쁨을 표시하지 않는다. `PRODUCT.md`의 "판정하지 않는다"를 따른다.
- **양심노트는 세션과 묶이지 않는다.** 한 장은 세션, 할 일, 메모장과 연결되지 않는 독립된 기록이다. `PRODUCT.md`에서 범위 밖인 세션 기록 저장을 건드리지 않는다.
- **저장 버튼 없이 자동 저장하고, 그 사실을 화면에 알린다.** 사용자가 정했다. 저장 버튼이 없어 저장 방법을 찾다가 다른 화면으로 가지 못할 수 있다는 걱정에서 나왔다. 버튼을 눌러야 저장되게 하면 누르지 않고 화면을 옮길 때 글이 사라지므로 자동 저장을 유지하고, 대신 "자동 저장됨" 표시와 마무리 동작인 완료 버튼을 둔다. 완료는 목록으로 돌아갈 뿐 따로 저장하지 않는다. 같은 표시를 메모장에도 둔다.
- **저장은 브라우저에 한다.** 메모장, 할 일 목록과 같은 기기 로컬 저장이며, `PRODUCT.md`의 "계정, 동기화, 여러 기기는 범위 밖"을 따른다.
- **기존 화면과 어울리게 만든다.** 사용자가 정했다. 색, 글꼴, 간격, 아이콘, 입력 칸과 버튼의 모양은 타이머, 메모장, 할 일 목록이 쓰는 것을 그대로 따르고, 밝은 테마와 어두운 테마 모두에서 도표가 읽혀야 한다. 단계 순서와 축 배치는 사용자가 확인용 화면을 보고 승인했다.
- **한국어 양식만 다룬다.** `PRODUCT.md`에서 다국어는 범위 밖이다.
- **아이콘을 우선하되 양식의 글자는 그대로 둔다.** 내비게이션과 조작은 아이콘과 접근성 텍스트로 두고(`docs/specs/icon-minimal-ui/` 방식), 덕목 이름, 안내 질문, 단계 이름은 뜻을 아이콘으로 전할 수 없어 텍스트로 둔다.

## 가정

되돌리기 쉬워서 에이전트가 정한 기본값이다. 바꾸고 싶으면 언제든 바꾼다.

- 안내 질문은 입력 칸 위의 고칠 수 없는 글자로 둔다. 사용자가 이 방식과 입력 전에만 보이는 placeholder를 둘 다 괜찮다고 했고, placeholder는 쓰기 시작하면 질문이 사라져서 전자를 골랐다.
- 주소는 `/conscience`다. 목록과 한 장 보기는 이 화면 안에서 오간다.
- 단계의 순서(중심부터 찜찜, 찜자, 자찜, 자명)와 축의 배치는 양식 도표를 화면으로 보고 읽은 것이다. 원본과 다르면 원본을 따른다.
- 같은 날짜의 양심노트는 나중에 만든 것이 위에 온다.
- 새로 쓰기만 누르고 아무것도 쓰지 않은 한 장도 목록에 남는다. 필요 없으면 삭제한다.
- 삭제 확인 문구는 "이 양심노트를 지울까요?"로 하고, 선택지는 확인과 취소 둘이다.
- 양심노트의 한 줄 바는 할 일 목록과 같은 조건에서만 보인다. 세션이 없을 때는 보이지 않는다.
- 좁은 화면에서는 도표가 최종 결론 글 아래로 내려간다.
- 도표는 보기만 한다. 도표를 눌러 단계를 고르지는 않는다.

## 범위 밖

- 인쇄, A4 양식 그대로의 출력: 요청되지 않았다. 필요해지면 따로 다룬다.
- 영어, 스페인어, 독일어 등 외국어 양식과 어린이용 양식: 한국어 양식만 다룬다.
- 여러 장의 통계, 추이 그래프, 덕목별 평균: "판정하지 않는다"와 부딪힌다.
- 검색, 태그, 사안 분류: 목록은 날짜순 하나만 둔다.
- 기기 간 동기화, 서버 저장: `PRODUCT.md`에서 범위 밖이다.
- 세션이나 할 일과 양심노트를 연결하는 것: 독립된 기록으로 두기로 했다.

## 보류

- `PRODUCT.md` 정의의 수정: 지금 정의는 "웹 타이머"이고 양심노트는 타이머와 무관한 성찰 기록이다. 메모장, 할 일 목록에 이어 앱의 범위가 넓어지는 것을 정의에 반영할지는 `define-product`로 따로 다룬다.

## 남은 위험

- 양식에는 허가 없는 상업적 이용을 금한다는 문구가 있고, 이 저장소는 강의용 템플릿이다. 안내 질문 원문이 저장소와 함께 배포된다. 지금은 만든 사람 혼자 쓰지만, 강의 자료로 나가거나 다른 사람에게 앱을 열 때는 저작권자 또는 홍익학당의 허가를 확인해야 한다.
- 브라우저에만 저장하므로 브라우저 데이터를 지우면 쓴 양심노트가 모두 사라진다. 파일로 내려받아 두는 것이 유일한 백업이다. 불러오기는 글 속의 `[사안]`, `[몰입]` 같은 줄을 구획으로 읽으므로, 본문에 그런 줄을 그대로 적은 한 장은 다르게 돌아올 수 있다.
- 헤더에 아이콘이 하나 더 늘어 좁은 폰에서 한 줄에 들어가지 않을 수 있다. 비좁으면 ritus 글자를 줄이거나 숨기는 조정이 필요하다(`docs/specs/unified-navigation/spec.md`의 남은 위험과 같다).
- 폰에서 가상 키보드가 올라오면 쓰고 있는 칸이 가려질 수 있다. 실기기에서 확인해야 한다.
