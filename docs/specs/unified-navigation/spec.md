# 화면 간 내비게이션 통일과 세션 유지

## 사용자에게 보이는 결과

타이머, 메모장, 할 일 목록 세 화면의 상단 헤더 같은 자리에 아이콘 세 개(타이머, 메모장, 할 일 목록)가 나란히 놓이고, 지금 있는 화면의 아이콘이 강조된다. 어느 화면에서든 나머지 두 화면으로 한 번에 갈 수 있다.

세션이 도는 중에 다른 화면으로 가도 시간은 계속 흐르고 소리도 그대로 울린다. 메모장과 할 일 목록에서는 헤더 아래 한 줄 바(작은 링, 남은 시간, 조작 아이콘)로 세션을 보고 조작한다. 브라우저 탭 제목의 남은 시간도 어느 화면에서나 이어진다.

메모장은 독립 화면 `/memo`가 된다. 뒤로가기와 새로고침이 다른 화면과 똑같이 동작한다.

세션 중에 할 일 목록에서 다른 할 일을 누르면, 지금 세션을 그만두고 새로 시작할지 먼저 묻는다.

화면 배치는 다음과 같다. `[ ]`는 현재 화면 강조다.

```
타이머
┌────────────────────────────────────┐
│ ritus        [◷] ✎  ☰  │  ◐  ♪   │
├────────────────────────────────────┤
│             ( 25:00 )              │
│                 ▶                  │
└────────────────────────────────────┘

메모장 (세션 중)
┌────────────────────────────────────┐
│ ritus         ◷ [✎] ☰  │  ◐  ♪   │
├────────────────────────────────────┤
│ ◔ 12:34  ❚❚ ■                      │
├────────────────────────────────────┤
│ 메모 본문...                       │
├────────────────────────────────────┤
│ Ln 3, Col 12, Pos 40 · 30줄 · 150자│
└────────────────────────────────────┘

할 일 목록 (세션 중)
┌────────────────────────────────────┐
│ ritus         ◷  ✎ [☰] │  ◐  ♪   │
├────────────────────────────────────┤
│ ◔ 12:34  ❚❚ ■                      │
├────────────────────────────────────┤
│ [ 오늘 무엇을 할까요?        ] [+] │
│ ◷ 보고서 초안                  ×2  │
└────────────────────────────────────┘
```

## 승인된 범위

- 세 화면 공통 상단 헤더: 왼쪽에 ritus, 가운데 묶음에 타이머·메모장·할 일 목록 아이콘, 오른쪽에 테마와 음소거
- 메모장을 독립 화면 `/memo`로 분리
- 세션(진행 상태, 남은 시간, 소리)이 세 화면 사이를 오가도 이어짐
- 메모장과 할 일 목록에서 세션을 보여 주고 조작하는 한 줄 바
- 세션 중 다른 할 일을 눌렀을 때의 확인 절차
- 기존의 제각각인 이동 수단 제거: 메모장의 닫기(✕), 할 일 목록의 "‹ ritus" 링크와 중복 타이머 아이콘, `/timer`의 "‹ 목록" 링크

## 수용 기준

### 내비게이션

- [x] 타이머, 메모장, 할 일 목록 화면 모두 상단 헤더의 같은 자리에 타이머·메모장·할 일 목록 아이콘이 같은 순서로 보인다.
- [x] 지금 있는 화면의 아이콘이 나머지 둘과 시각적으로 구분되고, 스크린리더는 그것이 현재 화면임을 읽는다.
- [x] 세 아이콘은 글자 없이 아이콘만 보이고, 스크린리더는 각각 "타이머", "메모장", "할 일 목록"을 읽는다.
- [x] 어느 화면에서든 다른 두 화면으로 아이콘 한 번으로 이동한다.
- [x] 테마와 음소거 아이콘이 세 화면 모두 헤더 오른쪽에 있다.
- [x] 메모장에 닫기(✕)가 없고, 할 일 목록에 "‹ ritus" 링크와 별도 타이머 아이콘이 없다.
- [x] 폰 너비에서도 헤더가 가로 스크롤 없이 한 줄에 들어온다.

### 메모장 분리

- [x] 메모장 아이콘을 누르면 주소가 `/memo`로 바뀌고 메모장이 열린다.
- [x] `/memo`에서 새로고침하면 메모장에 그대로 있고, 쓰던 글도 남아 있다.
- [x] 타이머에서 메모장으로 간 뒤 브라우저 뒤로가기를 누르면 타이머로 돌아온다.
- [x] 메모장의 본문, 자동 저장, 내려받기, 상태 표시줄, txt/md 형식과 프리뷰는 `docs/specs/memo-pad/spec.md`의 수용 기준 그대로 동작한다.

### 세션 유지

- [x] 세션이 도는 중에 메모장이나 할 일 목록으로 이동해도 남은 시간이 끊기지 않고 줄어든다. 타이머로 돌아오면 그사이 흐른 만큼 줄어 있다.
- [x] 다른 화면에 있는 동안에도 구간 전환 소리, 박자 소리, 종료 소리가 타이머 화면에 있을 때와 똑같이 울린다.
- [x] 세션 중에는 메모장과 할 일 목록의 헤더 아래에 한 줄 바가 보이고, 작은 링과 남은 시간이 계속 갱신된다.
- [x] 한 줄 바에서 일시정지/이어서, 그만두기를 할 수 있다. 일시정지한 채 화면을 옮겨도 일시정지 상태가 유지된다.
- [x] 브라우저 탭 제목의 남은 시간이 세 화면 어디에서나 갱신된다.
- [x] 다른 화면에 있을 때 세션이 끝나면 종료 소리가 울리고, 한 줄 바에 같은 설정으로 다시 시작하는 아이콘이 보인다.
- [x] 세션이 돌지 않을 때 메모장의 한 줄 바에는 지금 설정된 시간과 시작 아이콘이 보이고, 시작하면 메모장에 머문 채로 세션이 돈다.
- [x] 타이머 설정 화면에서 정한 제목, 시간, 번갈아 반복 설정은 다른 화면에 다녀와도 그대로다.

### 세션 중 다른 할 일 누르기

- [x] 세션이 돌거나 일시정지된 상태에서 할 일 카드를 누르면, 지금 세션을 그만두고 새로 시작할지 묻는 확인이 뜬다. 세션은 묻는 동안에도 계속 흐른다.
- [x] 확인하면 지금 세션이 끝나고, 누른 할 일의 제목이 채워진 타이머 설정 화면으로 간다.
- [x] 취소하면 할 일 목록에 그대로 있고 세션도 그대로 돈다.
- [x] 세션이 돌지 않을 때 할 일 카드를 누르면 지금처럼 묻지 않고 바로 그 제목의 타이머 설정 화면으로 간다.
- [x] 세션 중에도 할 일 추가, 편집, 삭제는 확인 없이 된다.
- [x] 세션을 완주하면 그 세션을 시작할 때 고른 할 일의 완주 횟수가 1 오른다. 세션 중에 다른 화면을 오갔어도, 다른 할 일을 눌렀다가 취소했어도 마찬가지다.

## 확정된 제약과 근거

- **내비게이션은 상단 헤더에 둔다.** 사용자가 하단 탭 바, 폰과 큰 화면을 달리하는 안과 비교해 골랐다. 하단 탭 바는 메모장에서 가상 키보드와 부딪히고 상태 표시줄 아래에 한 줄을 더 만든다. 상단은 폰과 큰 화면이 같은 구조를 써서 `PRODUCT.md`의 "큰 화면과 폰이 같은 하나의 세션 화면을 쓴다"와 맞는다.
- **메모장은 독립 화면 `/memo`다.** 사용자가 정했다. 세 아이콘이 나란히 놓이면 세 화면이 같은 급으로 읽히므로 동작도 같아야 하고, 뒤로가기와 새로고침이 기대대로 움직인다. 이 결정은 `docs/specs/memo-pad/spec.md`의 "메모장은 페이지 이동이 아니라 같은 화면 안에서의 전환이어야 한다"를 대신한다. 그 문장의 근거였던 "메모장을 열고 닫아도 세션이 끊기지 않는다"는 그대로 지킨다.
- **세션은 화면을 옮겨도 이어진다.** 사용자가 정했다. 앱이 앞에 떠 있는 동안에는 어느 화면을 보든 세션이 진행되어야 한다. `PRODUCT.md`의 "시작할 때 정한 것이 세션 내내 눈앞에 남는다"를 다른 화면에서는 한 줄 바와 탭 제목으로 지킨다.
- **세션 중 다른 할 일을 누를 때만 확인을 받는다.** 사용자가 카드 비활성화, 묻지 않고 바꾸기와 비교해 골랐다. 잘못 누른 한 번에 세션이 사라지지 않게 하되, 바꾸고 싶을 때는 그 자리에서 바꿀 수 있다. 화면 이동 자체는 세션을 건드리지 않으므로 묻지 않는다.
- **확인하는 순간 지금 세션이 끝난다.** 새 세션을 시작할 때까지 옛 세션을 살려 두는 안을 사용자와 검토하고 택하지 않았다. 타이머 화면이 새 설정과 옛 세션을 동시에 보여 줘야 하고, 준비하는 사이 옛 세션이 끝나 그만둔 할 일에 완주 횟수가 오르는 경우가 생기는 데 비해, 얻는 것은 확인부터 시작까지의 몇 초뿐이다. 마음이 바뀐 경우는 확인 창의 취소가 받는다.
- **아이콘을 우선한다.** 내비게이션 아이콘은 글자 없이 보이고 접근성 텍스트를 둔다(`docs/specs/icon-minimal-ui/` 방식). 확인 문구는 뜻을 아이콘으로 전할 수 없어 텍스트로 둔다.

## 가정

되돌리기 쉬워서 에이전트가 정한 기본값이다. 바꾸고 싶으면 언제든 바꾼다.

- 확인 문구는 "지금 세션을 그만두고 새로 시작할까요?"로 하고, 선택지는 확인과 취소 둘이다.
- 확인 뒤에는 세션을 자동으로 시작하지 않고 설정 화면에서 멈춘다. 지금 할 일 카드의 동작과 같다.
- 지금 세션을 시작한 바로 그 할 일을 다시 누르면 묻지 않고 타이머 화면으로 간다.
- 세션이 끝난 뒤(종료 화면 상태)에 할 일 카드를 누르면 묻지 않는다.
- 할 일 목록의 한 줄 바는 세션이 돌거나, 일시정지됐거나, 막 끝났을 때만 보인다. 세션이 없을 때는 보이지 않는다. 메모장의 한 줄 바는 지금처럼 항상 보인다.
- 타이머 화면에는 한 줄 바를 두지 않는다. 화면 자체가 세션을 보여 준다.
- `/timer`는 `/`와 같은 화면으로 계속 열린다.
- 헤더 왼쪽의 ritus는 글자만 보이고 링크가 아니다.

## 범위 밖

- 새로고침하거나 탭을 닫았다 열어도 세션이 이어지게 하는 것: 지금도 새로고침하면 세션이 사라지며, 이번 작업은 화면 간 이동만 다룬다.
- 하단 탭 바, 화면 너비에 따라 달라지는 내비게이션 배치: 사용자가 상단 헤더로 정했다.
- 메모장과 할 일 목록에서 세션 시간을 조정하는 것: 시간은 타이머 화면에서만 바꾼다(메모장 스펙의 가정을 그대로 따른다).
- 메모장 기능 자체의 변경: 위치만 옮기고 기능은 그대로 둔다.

## 보류

- `PRODUCT.md` 경험 원칙 "세션이 도는 동안 화면에는 지금 하기로 한 것과 남은 시간만 둔다"의 수정: 메모장 스펙에서 이미 보류한 항목이다. 세션 중 할 일 목록까지 볼 수 있게 되면서 어긋남이 커지므로 `define-product`로 따로 다룬다.

## 남은 위험

- 한 줄 바에는 세션 제목이 없어서, 메모장이나 할 일 목록에 오래 머물면 "지금 하기로 한 것"이 화면에서 사라진다. 탭 제목에는 남지만 전체 화면이나 설치한 PWA에서는 탭 제목이 보이지 않는다. 써 보고 불편하면 한 줄 바에 제목을 넣는 것을 다시 본다.
- 다른 화면에 있다가 화면이 꺼졌을 때 소리가 이어지는지는 기존 타이머와 같은 조건에 놓인다. 실기기에서 세 화면 모두 확인해야 한다.
- 폰 너비 헤더에 ritus, 내비게이션 아이콘 셋, 테마, 음소거가 한 줄에 들어가야 한다. 좁은 폰에서 비좁으면 ritus 글자를 줄이거나 숨기는 조정이 필요할 수 있다.
