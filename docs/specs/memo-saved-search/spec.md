# 메모 저장 목록 검색

## 사용자에게 보이는 결과

저장한 메모 목록 위에 돋보기 아이콘이 생긴다. 누르면 검색 칸이 열리고, 글을 치면 그 글을 모두 포함한 저장 메모만 목록에 남는다. 닫기(×)를 누르면 전체 목록으로 돌아간다. 양심노트 검색과 같은 방식이다.

## 정한 것

- **검색 대상은 저장한 메모 전체 글이다.** 임시 보관본도 같은 기준으로 검색한다.
- **일치 규칙은 양심노트 검색과 같다.** 띄어쓰기로 나눈 낱말을 모두 포함해야 하고, 영문은 대소문자를 구분하지 않는다.
- **검색은 저장 목록에서만 한다.** 편집 중인 글 안에서 찾기는 하지 않는다.
- **일치하는 메모가 없으면 "일치하는 메모가 없습니다"를 보인다.** 저장한 메모가 하나도 없을 때의 문구와는 다르다.
- **검색어는 목록을 떠나면 지운다.** 편집으로 돌아가거나 메모를 불러오면 검색 칸과 검색어가 함께 지워진다.
- **검색은 이 기기 안에서만 한다.** 네트워크 요청을 하지 않는다.

## 범위 밖

- 편집 중인 글 안에서 찾기와 찾아가기.
- 카드에 일치한 위치 표시.
- 날짜나 형식으로 거르기.

## 수용 기준

- [x] 저장 목록 위의 돋보기를 누르면 검색 칸이 열리고, 글을 치면 목록이 바로 줄어든다.
- [x] 저장한 메모의 본문 어디에든 낱말이 모두 들어 있으면 그 메모가 남는다.
- [x] 영문 검색은 대소문자를 구분하지 않는다.
- [x] 일치하는 메모가 없으면 "일치하는 메모가 없습니다"가 보인다.
- [x] 닫기(×)를 누르면 검색 칸이 사라지고 전체 목록이 돌아온다.
- [x] 편집으로 돌아가거나 메모를 불러오면 검색어가 지워진다.
- [x] 폰 너비(360px)에서 검색 칸이 가로 스크롤 없이 들어온다.
- [x] `docs/manual.md`의 메모장 절에 검색 사용법을 적는다.
