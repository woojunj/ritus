# 양심노트 검색

## 사용자에게 보이는 결과

양심노트 목록 위에 돋보기 아이콘이 생긴다. 누르면 검색 칸이 열리고, 글을 치면 그 글이 들어 있는 장만 목록에 남는다. 지우면 전체 목록으로 돌아간다. 지난번에 어떤 사안을 돌아봤는지 목록을 하나씩 열지 않고 찾을 수 있다.

## 정한 것

- **검색 대상은 글 전체다.** 사안, 여섯 덕목의 질문 답, 최종 결론을 모두 본다. 날짜와 신호는 검색 대상이 아니다.
- **일치는 단순하게 본다.** 입력한 글자가 그대로 들어 있으면 일치한다. 영문은 대소문자를 구분하지 않는다. 한글은 조사가 붙어도 일치한다. 예를 들어 "약속"은 "약속에"에도 걸린다.
- **띄어쓰기로 나눈 낱말을 모두 포함해야 일치한다.** "약속 늦"을 치면 두 낱말이 모두 들어 있는 장만 남는다.
- **결과 장에는 어느 칸에서 일치했는지 이름을 붙인다.** 예: "사안, 몰입". 카드를 누르면 그 장이 열리는 것은 지금과 같다.
- **검색 중에도 목록의 기존 동작은 그대로 둔다.** 더하기, 붙여넣기, 불러오기, 모두 저장, 도우미, 새로 쓰기는 검색 중에도 쓸 수 있다.
- **검색어는 목록을 떠나면 지운다.** 저장하지 않는다. 기록을 남기지 않는 것이 이 앱의 방향과 맞다.
- **검색은 이 기기 안에서만 한다.** 검색어와 글을 어디로도 보내지 않는다.
- **일치하는 장이 없으면 빈 목록 자리에 "일치하는 양심노트가 없습니다"를 보인다.** 아이콘을 우선하는 원칙에 따라 문구는 이 한 줄만 둔다.

- **돋보기 아이콘은 "양심노트" 제목 오른쪽에 둔다.** 헤더 아이콘 묶음과는 나눠서 제목 쪽에 붙인다.
- **검색 칸은 헤더 아래 한 줄로 펼친다.** 헤더와 아이콘은 검색 중에도 그대로 보인다. 검색 칸이 열리면 목록은 그만큼 아래로 내려간다.
- **검색 칸의 닫기(×)를 누르면 줄이 사라지고, 목록은 원래 자리로 돌아간다.** 검색을 지우는 것과 닫는 것은 같은 결과다.
- **결과 카드에는 일치한 칸 이름을 보인다.** 예: "사안, 몰입". 카드 한 줄 아래에 작은 글씨로 붙인다.

## 범위 밖

- 신호로 거르기. 판정하는 느낌을 줄 수 있어 따로 정한 뒤에 다룬다.
- 날짜 범위로 거르기.
- 오타 허용, 낱말의 형태 변화 인식, 정규식 검색.
- 검색 결과의 일치 글자를 색으로 강조하기.
- 할 일 목록 검색. 목록이 길어지면 따로 정한다.
- 여러 화면을 가로지르는 검색.

## 수용 기준

- [ ] 양심노트 목록에서 돋보기 아이콘을 누르면 검색 칸이 열리고, 칸에 글을 치면 목록이 바로 줄어든다.
- [ ] 사안, 덕목 답, 최종 결론 가운데 한 곳에라도 입력한 글자가 있으면 그 장이 남는다.
- [ ] "약속 늦"처럼 띄어쓰기로 나눈 낱말은 모두 들어 있어야 그 장이 남는다.
- [ ] 영문 검색은 대소문자를 구분하지 않는다.
- [ ] 일치하는 장이 하나도 없으면 "일치하는 양심노트가 없습니다"가 보인다.
- [ ] 검색을 지우면 전체 목록으로 돌아간다.
- [ ] 검색 중에도 카드 누르기, 더하기, 붙여넣기, 도우미가 지금처럼 동작한다.
- [ ] 검색어는 목록을 떠난 뒤 남아 있지 않다.
- [ ] 검색 기능은 네트워크 요청을 하지 않는다. 이 기기 안의 목록만 다룬다.
- [ ] 돋보기 아이콘은 제목 오른쪽에 있고, 검색 칸은 헤더 아래 한 줄로 열린다. 닫기(×)를 누르면 줄이 사라진다.
- [ ] 일치한 장 카드에 일치한 칸 이름("사안, 몰입" 등)이 보인다.
- [ ] 폰 너비(360px)에서 헤더와 검색 칸이 가로 스크롤 없이 들어온다.
- [ ] `docs/manual.md`의 양심노트 목록 절에 검색 사용법을 함께 적는다.

## 검증 방법

- 단위 테스트: 일치 규칙(낱말 모두 포함, 대소문자, 조사가 붙은 한글, 빈 검색어), 일치한 칸 이름 계산.
- e2e: 검색으로 장을 좁히고, 지우고, 일치하는 장이 없을 때의 문구를 확인한다. 폰 너비 가로 스크롤도 본다.
