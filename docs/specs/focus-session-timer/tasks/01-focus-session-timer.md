# 01 — 집중 세션 타이머

## Outcome

설정 화면(제목 입력, 원/숫자 시간 설정) → 진행 화면(제목과 남은 시간 표시, 탭 제목 갱신,
일시정지) → 종료 화면(소리·깜빡임·격려 메시지, 재시작, 중도 종료 시 조용한 복귀)까지
이어지는 세션 하나의 전체 흐름을 사용자 관점에서 처음부터 끝까지 전달한다.

## Blockers

None.

## Acceptance criteria

- [x] 제목을 적고 시작하면 세션 내내 그 문장이 화면에 보이고, 비운 채로도 시작할 수 있다
- [x] 처음 화면은 25분이 기본값이며 바로 시작할 수 있다
- [x] 원 드래그와 숫자 입력이 서로 같은 값을 가리키며 1분 미만·60분 초과는 막힌다
- [x] 시작 시 소리가 한 번 울린다
- [x] 다른 탭으로 가면 탭 제목이 `24:13 · 결제 모듈 리팩터링` 형태로(제목이 없으면 남은
      시간만) 갱신된다
- [x] 일시정지·재개가 그 자리에서 이어지고 멈춘 횟수는 어디에도 나타나지 않는다
- [x] 남은 시간이 0에 닿으면 소리·시계 전체 깜빡임·무작위 격려 메시지가 함께 뜬다
- [x] 종료 화면을 누르면 깜빡임이 멈춘다
- [x] 종료 화면에서 같은 제목·같은 시간으로 즉시 재시작할 수 있다
- [x] 세션 도중 그만두면 메시지도 깜빡임도 없이 처음 화면으로 돌아간다
- [x] 소리를 끌 수 있고, 꺼도 화면만으로 시작·종료를 구분할 수 있다
- [x] 창 폭에 따라 시계·제목이 함께 커지고 작아지며, 폰 폭에서도 세로 배치가 무너지지
      않는다
- [x] 새로고침하면 세션 기록 없이 처음 화면으로 돌아간다
