# 오프라인 지원

## 사용자에게 보이는 결과

인터넷에 연결된 상태로 ritus를 한 번 열어 두면, 그 뒤에는 인터넷이 없어도 앱이 열린다. 한 번도 열지 않은 화면을 포함해 모든 화면에서 세션을 돌리고 글을 쓸 수 있다.

## 정한 것

- **서비스 워커를 직접 쓴다.** `public/sw.js` 하나로 둔다. 데이터는 모두 브라우저 저장소에 있으므로 화면을 그리는 파일만 보관하면 된다.
- **설치할 때 모든 화면을 받아 둔다.** 다섯 화면과 `/timer`의 HTML, 그 HTML이 가리키는 `/_next/static` 파일을 미리 보관한다.
- **화면은 온라인이면 늘 새로 받는다.** 화면 요청은 네트워크를 먼저 쓰고 실패할 때만 보관본을 낸다. 그래서 온라인 사용자는 새 배포를 바로 받는다. `/_next/static` 파일은 이름에 해시가 있어 보관본을 먼저 쓴다.
- **배포된 앱에서만 등록한다.** 개발 서버에서는 등록하지 않는다.

## 범위 밖

- 오프라인 상태를 화면에 알리기, 새 버전 알림.
- 오래된 배포의 정적 파일 정리.

## 수용 기준

- [x] 첫 화면만 연 뒤 네트워크를 끊어도, 다섯 화면과 `/timer`를 새로고침하면 열린다.
- [x] 네트워크가 끊긴 채 헤더의 아이콘으로 화면을 오갈 수 있다.
- [x] 네트워크가 끊긴 채 세션을 시작하면 시간이 흐른다.
- [x] 네트워크가 끊긴 채 메모장에 쓴 글이 새로고침 뒤에도 남는다.
